# 酒馆手记

一篇简短的 SillyTavern 入门分享，介绍角色与记忆、四个基础功能，以及小猫之神和夏瑾两套预设。

发布地址：[酒馆手记](https://lihuifree.github.io/sillytavern-guide/)。

## 文件

- `index.html`：文章正文、页面结构和分享摘要。
- `styles.css`：桌面、手机和打印样式。
- `favicon.svg`：本站图标。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

纯 HTML/CSS，无构建步骤、JavaScript、远程字体或第三方依赖。目录链接和资源路径适用于 GitHub Pages 项目站点。

## 预览与维护

在此目录运行 `python3 -m http.server 8765`，然后打开 `http://localhost:8765/`。修改正文时编辑 `index.html`；改动提交到 GitHub Pages 使用的分支后会自动部署。
